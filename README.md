# Swatchsmith: free browser demo

**Try it now:** https://kosmfit.github.io/swatchsmith-demo/

Swatchsmith recolours a whole folder of pixel-art sprites at once: pick colours or map a colour ramp to a palette,
limit changes to a painted region if you need to, and export every variant in one ZIP, with palettes and a lookup
texture plus ready-made Godot 4 / GLSL shaders for runtime palette swaps.

- This demo handles 3 sprites and 1 variant. Click **Try example sprites** if you don't have any to hand.
- Everything runs in your browser. Your images are never uploaded.
- The full version (no limits, works offline as a single file) is on itch.io: https://kosmfit.itch.io/swatchsmith

Example sprites: "Tiny Dungeon" by Kenney (kenney.nl), CC0.
Built with AI-assisted code; the tool itself contains no AI and never generates art.
